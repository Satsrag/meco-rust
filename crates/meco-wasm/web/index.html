Mongolian encoding converter 蒙古语编码转换

Type on the left, read the output on the right; the middle pane is the Zvvnmod hub and takes input too. Everything runs locally, in WebAssembly built from the Rust core. utn57 is a target only — meco has no decoder for it. Changing an encoding reconverts at once and switches to that encoding's font; characters that do not belong to a pane's encoding are marked red, in the text and in the code points under it. 左栏输入，右栏只读输出，中间是 Zvvnmod 中间码（也可直接输入）；全部由 Rust 核心编译的 WebAssembly 在浏览器本地完成。utn57 只作目标，meco 不能反向解码。切换编码会立即 重新转换并换用该编码的字体；不属于该栏编码的字符标红（文字和码点同时）。 loading WASM… / 加载中…
